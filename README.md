# 🤖 Streamlit Python Chatbot

A simple chatbot application built using Python and Streamlit.

## Features

- 💬 Interactive chat interface
- 🤖 Basic chatbot responses
- 🕐 Current time
- 📅 Current date
- 🐍 Python information
- 🎈 Streamlit information
- 🗑️ Clear chat button
- 💾 Chat history using Streamlit session state

## Requirements

- Python 3.8+
- Streamlit
